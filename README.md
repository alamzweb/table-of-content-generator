Automatically generate beautiful, customizable, and responsive tables of content from your content headings. Designed to match premium SaaS documentation interfaces.

== Description ==

Table of Content Generator is a premium-tier frontend interaction framework wrapped seamlessly as an ultra-lightweight standalone WordPress engine. It parses rendering content execution stacks on the fly to automatically map structure hierarchies, resolve nested configurations, assign programmatic anchor nodes, and inject beautifully structured, fully accessible reading navigation indices.

Unlike conventional utilities that drop static, uninspired bullet lists into your text blocks, this platform delivers production-grade layout components resembling premium developer-centric platforms like GitBook, Notion, Stripe Docs, and modern tech ecosystem architectures.

= Key Architecture Standards Implemented =
* **Complete Layout Execution Control:** Global content injection parameters remain fundamentally offline by default. The subsystem will never force injections onto live post instances until explicit structural rules are committed.
* **Independent Execution Interfaces:** Both shortcode expressions and native Block blueprints execute entirely outside global automation configurations.
* **Performance Pipeline Isolation:** Zero dependency bloat. Built completely on pure modern ES6+ Vanilla JavaScript and lightweight CSS selectors. DOM recalculations and Intersection Observer threads run independently outside standard operational render-blocking lanes.
* **Granular Layout Controls:** Includes multi-level nested header filtering, custom color palette state maps, interactive toggle matrices, and modern layout presets out of the box.

== Features ==

* **Dynamic Structural DOM Parsing Engine:** Scans rendering nodes instantly across customizable nested ranges (H2, H3, H4, H5, H6) to construct hierarchical map definitions cleanly.
* **Automated Anchor Vector Formulation:** Programmatically checks existing element nodes or injects safe, unique deterministic identifier attributes dynamically behind the scenes.
* **Four Premium Structural Presets:** Choose from Modern SaaS Minimalist, Developer Docs Ecosystem (GitBook Style), Ultra Clean Plain Minimal, and Structured Boxed Card Shadow variations.
* **Intersection Observer Viewport Tracing:** Tracks live reader scrolling progress, actively highlighting current structural anchors dynamically in real-time as sections cross threshold vectors.
* **Ergonomic Viewport Scroll Ramping:** Avoid rigid jumping loops entirely; integrated native fluid anchor calculations step reading layout positions gently.
* **Responsive Fluid Fluidity Breakpoints:** Built explicitly from the ground up to handle extreme layout variations flawlessly across Desktop, Tablet, and Mobile screens.
* **Sticky Sidebar Context Pinning:** Locks elements layout structures directly into floating view limits alongside scrolling contents automatically when activated.

== Shortcodes section ==

To deploy reading navigation frameworks directly inside custom layout modules, templating files, hook systems, or modern page building canvases independent of global rules, execute the following shortcode signature string format:

`[toc_generator]`

== Gutenberg Block section ==

This engine registers a native system block called **Table of Content** directly within your default Block Editor. Simply search the layout canvas elements array, drop it down anywhere inside your content layout stack, and configure content mapping streams smoothly. The block functions automatically without global automation engines being turned on.

== Display Modes section ==

* **Global Content Automations:** Inject structured layouts dynamically using standard automated rules (Choose from: Prepended Before Content, Appended Content Base, or Positioned Explicitly Before First Active Heading).
* **Shortcode Blocks:** Run custom runtime-compiled render sequences inside your site wherever custom blocks occur.
* **Visual Gutenberg Block Canvas Elements:** Deliver distinct custom-positioned, high-performance rendering elements inside post compositions independently.

== Style Presets section ==

* **Modern:** The standard SaaS tech blog style layout archetype. Features polished light slate structures optimized for maximum layout contrast.
* **Documentation:** Modeled precisely after high-end developer-facing wiki systems. Employs crisp left vertical accent bars configured against user target color keys.
* **Minimal:** Strips out borders, complex shading models, and extra padding modules, leaving a highly professional, clean reading interface.
* **Card:** Wraps elements directly within clean modern shadow containers to give them an elegant floating appearance.

== Installation ==

1. Upload the entire extraction package folder `table-of-content-generator` directory straight up inside the target server directory `/wp-content/plugins/`.
2. Access your main administrative Dashboard interface, open the **Plugins** control view, and select **Activate** next to the plugin name.
3. Open the custom dedicated top-level application framework control board named **TOC Generator** to adjust settings.

== Frequently Asked Questions ==

= Does this system impact optimization scores or delay page loading metrics? = \
Absolutely not. The frontend code is completely optimized, containing zero heavy framework code or slow jQuery chains. It loads only minimal raw CSS/JS assets, resulting in negligible processing times.

= Will this break custom manual IDs already hardcoded into my content headings? = \
No. The engine reads your manual string values first. If an ID is already assigned to a heading element, the generator uses it directly without overriding it.

= Can I use this multiple times inside a single post layout? = \
Yes. You can place the Gutenberg block or shortcodes into your content layout as many times as you like. The parser runs perfectly without duplicating ID strings across the page.

= How does the sticky sidebar preset look on mobile viewports? = \
To maintain an optimal reading experience, the sticky sidebar behavior turns off automatically on mobile layouts. It drops back down cleanly into a normal block element so it won't block the reader's view.

= What custom post types are compatible with this automation engine? = \
The plugin searches your database for all publicly available post types. You can turn on tracking options for posts, pages, or custom documentation post types right from the settings page.

= Does the intersection observer trace heading shifts accurately when items match quickly? = \
Yes. The tracking loop uses precise calculation ranges to detect active viewports, updating active links accurately even when readers scroll rapidly through content.

= Are custom colors configured in settings saved securely? = \
Yes. All incoming hex values go through a strict validation loop using WordPress core `sanitize_hex_color` rules before being stored in the database.

= Can I hide the index layout completely on specific pages if global parsing is on? = \
Yes. If you turn off global parsing, you gain absolute control. You can then use shortcodes or blocks to selectively display the table of contents only where needed.

= Does this plugin support multi-language installations and localization strings? = \
Yes. The plugin is translation-ready and includes proper text-domain hooks (`table-of-content-generator`) to let you translate all interface text easily.

= What happens if a post doesn't contain any headings matching my settings? = \
The plugin handles this cleanly. If no matching headings are found, it stops processing quietly and renders nothing, avoiding empty placeholder boxes or broken layout elements.
